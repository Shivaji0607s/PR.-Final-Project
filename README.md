# 📊 Retail Sales Data Analysis & Interactive Dashboard

## 📌 Project Overview

The **Retail Sales Data Analysis & Interactive Dashboard** is an Excel-based data analytics project designed to transform raw retail transaction data into meaningful business insights.

This project uses Microsoft Excel's advanced features, formulas, data analysis tools, PivotTables, charts, and interactive dashboard elements to analyze sales performance, customer purchasing behavior, product performance, and regional sales trends.

The project provides a centralized dashboard that helps users understand key business metrics and make data-driven decisions through visual reports and analytical techniques.

## 🎯 Project Objectives

- Analyze retail sales transactions to identify important business trends and patterns.
- Evaluate product performance, customer behavior, and regional sales distribution.
- Apply advanced Excel functions and analytical tools to extract meaningful insights.
- Perform What-If Analysis to understand the impact of changing business variables.
- Develop an interactive dashboard using KPIs, charts, slicers, and timelines.
- Present business information through clear and professional data visualizations.

## 📂 Project Structure

The workbook contains the following analytical sections:

### 1. Dashboard
- Interactive sales dashboard.
- Key Performance Indicators (KPIs).
- Visual charts and business summaries.
- Interactive filtering capabilities.

### 2. Dataset
- Retail transaction records.
- Customer information.
- Product details and categories.
- Transaction dates and quantities.
- Unit prices and payment methods.
- Regional and customer segment information.
- Calculated Total Amount.

### 3. Date & Time Functions
- TODAY() function.
- NOW() function.
- Date and time calculations.

### 4. Regional Analysis
Separate transaction analysis for:
- West Region
- East Region
- North Region
- South Region

### 5. Conditional Formatting
- Highlighting customer transaction values.
- Visual comparison of quantities.
- Conditional formatting rules for identifying important records.

### 6. Transaction Timestamp
- Automatic timestamp functionality using NOW().
- Iterative calculation-based timestamp management.

### 7. What-If Analysis
**Goal Seek**
- Determines the required quantity to achieve a specified sales amount.

**Scenario Manager**
- Creates and compares different sales scenarios:
  - Low Sales
  - Normal Sales
  - High Sales

### 8. Linear Regression
- Regression analysis using Excel Data Analysis ToolPak.
- Examines the relationship between Quantity and Total Amount.
- Includes regression statistics, ANOVA, coefficients, and significance values.

### 9. PivotTables
The project includes PivotTable analysis for:

- Sales by Product Category.
- Sales by Region.
- Sales by Customer Segment.
- Sales by Payment Method.
- Monthly Sales Trends.

### 10. KPI Indicators with Conditional Formatting
- Total Revenue.
- Total Transactions.
- Total Quantity Sold.
- Average Order Value.
- Unique Customers.
- Total Unique Products.

### 11. Product Frequency Analysis
- Identifies product purchase frequency.
- Highlights repeating products.
- Finds the most frequently purchased product.

### 12. List Comparison Analysis
- Compares two customer lists.
- Extracts matching customer names.
- Identifies common entries between lists.

### Regression Analysis

The regression model examines the relationship between Quantity and Total Amount.

- Multiple R: 0.4581
- R Square: 0.2098
- Adjusted R Square: 0.2067
- Observations: 250

The R Square value indicates that approximately 20.98% of the variation in Total Amount is explained by Quantity in this regression model.
